# #62 LRC 行数上限

- `case_id`: `lrc.max-lines-reject`
- `status`: `Accepted`
- `owner`: `lyrics/lrc_parser` 与 `lyrics` source boundary
- `old_behavior`: `parse_lrc` 在达到 `MAX_LINES` 后静默停止，返回前 5000 行；调用方无法知道结果是不完整的。
- `new_contract`: 超过行数预算的输入返回明确的 `Rejected` 结果，不发布部分歌词，不写入持久 cache；未超过预算的输入保持原有 canonical lines。
- `user_impact`: 恶意或损坏歌词不会显示一份看似正常但缺行的歌词；用户能看到来源被拒绝并可继续尝试其他来源。
- `reason`: 部分成功会把截断内容误认为完整歌词，且无法让 source workflow 区分真实 miss 和预算拒绝。
- `replacement_tests`: `tests/test_behavior_corpus.py` 的 `lrc.max-lines-reject` baseline；未来 source result 的 `Rejected` contract test。
- `removal_condition`: 当前 parser 兼容返回 `list[LyricLine]` 的入口迁移到 typed `SourceResult` 后，删除静默截断路径。
