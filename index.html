Kotonoha

Wayland 桌面歌词

Kotonoha 通过 D-Bus 读取 MPRIS 播放状态，在 Wayland 图层上逐字显示歌词。任何实现 MPRIS 的播放器都可用，无需在播放器一侧安装组件。

安装

Kotonoha 设置

01

任何 MPRIS 播放器，无需插件

曲目与播放位置经 D-Bus 读取，播放器一侧无需适配。位置由本地时钟插值，不逐帧查询。

02

四个歌词来源

来源顺序、匹配条件、回退策略与本地缓存均可配置；当前来源无结果时按顺序回退到下一个。

03

点击穿透

启用后鼠标事件直接传递到下层窗口，歌词不再拦截点击。

04

主题与语言跟随系统

浅色、深色、跟随系统三态；界面语言同样可交由系统决定。两项均在设置窗口首页，修改后立即生效，无需重启。

浅色 / 深色 / 跟随系统简体 · 繁體 · English

05

全屏之上的图层窗口

需要实现 wlr-layer-shell 的合成器，KDE/KWin 与基于 wlroots 的合成器均可；GNOME/Mutter 退化为普通置顶窗口。毛玻璃另需 ext-background-effect-v1 或旧的 org_kde_kwin_blur，两者缺失时仅保留半透明，相关选项自动禁用。

安装

Gentoo 使用 gentoo-zh overlay，Arch 使用 AUR 的 kotonoha-git，NixOS 使用 flake，也可以从源码构建。

sudo emerge --ask app-eselect/eselect-repository
  sudo eselect repository enable gentoo-zh
  sudo emaint sync -r gentoo-zh
  
  # live ebuild 没有任何关键字
  echo 'media-plugins/kotonoha **' | sudo tee /etc/portage/package.accept_keywords/kotonoha
  
  sudo emerge --ask media-plugins/kotonoha::gentoo-zh
